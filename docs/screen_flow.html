화면별 동작

버튼과 키

그림에 없던 세부는 아래처럼 정했습니다. 모든 버튼은 마우스로 누르거나, 방향키로 고르고 Enter로 누를 수 있습니다.

메인 Menu 씬

시작이어하기설정종료
  • 시작 → 스테이지 선택.
  • 이어하기 → 아직 깨지 않은 스테이지 중 가장 앞 스테이지를 바로 시작. 깬 스테이지가 하나도 없으면 비활성.
  • 종료 → 게임을 닫습니다. 다른 화면에는 종료가 없습니다.
  • 뒤에서 여우가 스테이지 1 위에서 쉬고, 카메라가 천천히 돕니다.

스테이지 선택

스테이지 칸들메인으로 (Esc)
  • 모든 스테이지를 번호·이름·크기와 함께 보여 주고, 해금된 것만 누를 수 있습니다. 잠긴 칸은 자물쇠 표시.
  • 스테이지 1은 처음부터 열려 있고, N을 깨면 N+1이 열립니다.
  • 깬 스테이지에는 최고 기록(가장 빠른 클리어 시간)을 표시합니다.

게임 Main 씬

ReadyPlayingClearFail
  • Ready: "준비… 시작!" 약 1.2초. 이동할 수 없습니다.
  • Playing: 시간이 흐르고 화면 위에 표시됩니다. R 다시 시작.
  • Clear: 기록 저장, 다음 스테이지 해금. 버튼 "다음 스테이지(Enter)" · "스테이지 선택". 마지막 스테이지면 "엔딩 보기".
  • Fail: "다시 하기(R)" · "그만하기"(→ 메인).

일시정지 Esc

계속메인으로
  • Playing 중 Esc로 열고, 다시 Esc나 "계속"으로 닫습니다. 그동안 시간과 여우가 멈춥니다.

엔딩

메인으로
  • 마지막 스테이지를 깨고 "엔딩 보기"를 누르면 나옵니다. 축하 문구, 깬 스테이지 수, 기록 합계, 여우가 기뻐하는 모습.

설정

음량진행 초기화메인으로 (Esc)
  • 음량 슬라이더(0~100)는 저장되어 다음 실행에도 유지됩니다. 지금은 게임에 소리가 없어서, 소리를 넣으면 이 값이 적용됩니다.
  • 진행 초기화: 해금과 기록을 지웁니다. 한 번 더 확인합니다.
구조

씬과 저장

항목내용
씬Menu(메인·스테이지 선택·설정·엔딩, 빌드 첫 씬) + Main(게임·일시정지·결과). 화면 이동은 SceneFlow 한 곳에서.
저장SaveData: 해금된 스테이지 수, 스테이지별 최고 기록, 음량. Windows PlayerPrefs에 JSON으로.
기록 키스테이지마다 id를 둡니다. 맵툴로 저장하면 자동으로 생기고, 아직 없는 파일은 이름을 대신 씁니다. 그래서 맵툴에서 스테이지 순서를 바꿔도 기록이 따라갑니다.
UI지금 게임 UI처럼 코드로 만듭니다. 공통 모양(패널, 버튼, 글꼴)은 UiKit으로 모아 메뉴와 게임이 같이 씁니다.
맵툴"이 스테이지로 플레이"는 지금처럼 게임 씬으로 바로 들어갑니다. 결과 창의 버튼으로 메뉴 씬에 갈 수 있습니다.

UI 그림

Codex로 만든 그림 세트

ChatGPT 계정으로 Codex 이미지 생성을 써서 만들었습니다. 모두 투명 PNG이고, 패널과 버튼은 늘려도 모서리가 찌그러지지 않게 9-slice 테두리를 넣었습니다. 원본은 art/ui_original, 게임에서 쓰는 파일은 Assets/Textures/UI/gen에 있습니다.
