레버, 누름판, 미는 블록

여우가 물건을 건드리면 지형이 바뀌고, 그래서 못 가던 곳에 갈 수 있게 됩니다. 레버를 당기면 돌기둥이 솟아 다리가 되고, 누름판을 누르는 동안 땅이 오르내리고, 블록을 밀어 구멍을 메웁니다. 모두 지금의 턴 방식과 "클리어 가능" 검증 안에서 동작합니다.

작성 2026-10-06대상 FoxGame (Unity 6000.5)상태 완료
장치

건드리는 것 셋, 바뀌는 땅 둘

장치와 바뀌는 땅은 채널(1 2 3 4)로 이어집니다. 같은 색끼리 연결되고, 채널에 켜진 장치가 하나라도 있으면 그 채널은 켜짐입니다.

레버

L
  • 레버 쪽으로 걸어가 부딪히면 당깁니다. 여우는 제자리, 한 턴이 지납니다.
  • 당길 때마다 켜짐 ↔ 꺼짐이 바뀝니다 (계속 유지).
  • 레버 칸은 바위처럼 막혀 있어 올라설 수 없습니다.

누름판

P
  • 여우나 블록이 올라가 있는 동안만 켜집니다.
  • 내려오면 바로 꺼집니다. 블록을 올려 두면 계속 켜 둘 수 있습니다.
  • 기존 스위치(W, 한 번 밟으면 문이 영원히 열림)와는 따로입니다.

미는 블록

K
  • 블록 쪽으로 걸어가면 한 칸 밀고 여우도 한 칸 들어갑니다.
  • 건너편이 막혔거나(바위·레버·문·블록·맵 밖) 더 높은 땅이면 밀리지 않습니다. 낮은 땅으로는 떨어집니다.
  • 구멍으로 밀면 떨어져 구멍을 메웁니다. 그 칸은 밀었던 칸 높이의 땅이 됩니다.
  • 누름판을 누르고, 점프로 넘을 수는 있지만 올라설 수는 없습니다. 얼음에서 미끄러지지 않습니다.

솟는 다리

B
  • 꺼짐: 구멍 (자리에 옅은 표시). 켜짐: 아래에서 돌기둥이 솟아 땅이 됩니다.
  • 다리 위에 서 있는데 꺼지면 여우는 떨어지고, 블록은 떨어져 그 칸을 메웁니다.

승강 땅

E
  • 꺼짐 높이와 켜짐 높이를 따로 정합니다 (예: 1층 ↔ 3층).
  • 올라가면 계단 사이 디딤돌이, 내려가면 막던 벽이 길이 됩니다.
  • 위에 선 여우나 블록은 같이 오르내립니다.
한 턴의 순서

건드림 → 지형 변화 → 적·발판

  1. 여우 행동: 걷기·점프·밀기·당기기·기다리기 중 하나.
  2. 무너지는 칸, 스위치(기존), 블록 이동·구멍 메우기, 레버 바꾸기.
  3. 채널 다시 계산: 레버 켜짐 + 누름판 위의 여우·블록.
  4. 바뀐 땅 반영: 다리가 사라진 칸의 블록은 떨어져 메움, 여우는 떨어짐.
  5. 턴 +1 → 발판·적 이동 → 부딪힘 확인 (지금과 같음).
여우K→ 밀기 → 여우메움
파일 형식

스테이지 파일 버전 5

"rows":     [ "..B..", "L.P.E" ],   // 새 바닥 기호: L 레버, P 누름판, B 솟는 다리, E 승강 땅
"items":    [ ".K...", "S...G" ],   // 새 물건: K 미는 블록
"channels": [ "..1..", "1.2.2" ],   // 장치·바뀌는 땅의 채널 1~4 (그 밖은 .)
"floorsOn": [ ".....", "....3" ]    // 승강 땅이 켜졌을 때 층 (그 밖은 .)

버전 4 이하 파일은 장치가 없는 것으로 읽습니다. 검증은 채널에 켜는 장치가 없거나 바뀌는 땅이 없으면 경고합니다.

맵툴

붓과 채널

  • 붓 추가: 레버, 누름판, 솟는 다리, 승강 땅, 블록.
  • 채널 고르기 (C 키로 1→2→3→4). 장치·바뀌는 땅을 칠하면 지금 채널이 붙습니다.
  • 승강 땅은 칠할 때 높이 붓의 층이 "켜졌을 때 층"이 됩니다. 칸에 "1→3" 처럼 보입니다.
  • 그리드에서 장치·땅은 채널 색 테두리로, 블록은 나무 상자로 그립니다.
  • 검증은 블록 위치, 메운 구멍, 레버 상태까지 따져 한 판에 모든 보석을 모을 수 있는지 봅니다.
