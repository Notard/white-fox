눈덩이, 부엉이, 떠다니는 발판

여우가 한 번 행동할 때마다 적과 발판도 한 칸씩 움직이는 턴 방식입니다. 반사신경이 아니라 타이밍을 읽는 퍼즐이 되고, 맵툴의 "클리어 가능" 검증도 그대로 동작합니다. 걸음·착지·보석·클리어 연출도 함께 넣습니다.

작성 2026-10-06대상 FoxGame (Unity 6000.5)상태 구현 중
규칙

한 턴에 일어나는 일

여우 행동 = 1턴

턴
  • 걷기, 점프, 부딪히기, 그리고 새로 생긴 Q 기다리기가 모두 한 턴입니다.
  • 얼음에서 여러 칸 미끄러져도 한 턴입니다.
  • 순서: 여우 이동 → 발판 이동(타고 있으면 같이) → 적 이동 → 부딪혔는지 확인.

눈덩이 · 부엉이

적
  • 맵툴에서 그린 길을 끝까지 갔다가 되돌아오기를 반복합니다.
  • 눈덩이는 땅 위로만, 부엉이는 날아서 구멍 위로도 다닙니다.
  • 적이 있는 칸으로 들어가거나, 적이 여우 칸으로 들어오면 실패입니다. 점프로 적을 넘는 것은 괜찮습니다.

떠다니는 발판

발판
  • 구멍 칸으로 이루어진 길을 왕복합니다. 발판이 있는 구멍 칸은 땅처럼 설 수 있습니다.
  • 발판 위에 서 있으면 발판과 함께 다음 칸으로 실려 갑니다.
  • 발판이 없는 구멍으로 가면 지금처럼 떨어집니다.

연출

✦
  • 걸을 때 발자국(풀이 눌린 자국)이 남았다가 천천히 사라집니다.
  • 점프 착지 때 흙먼지가 피어오릅니다.
  • 보석 주변에 작은 반짝임이 계속 일어납니다.
  • 클리어하면 카메라가 여우에게 다가갑니다.
  • 적과 발판이 다닐 길은 바닥에 옅은 점으로 보여 줍니다.
파일 형식

스테이지 파일 버전 4: movers

"movers": [
  { "kind": "snowball", "path": [ {"x":2,"y":0}, {"x":2,"y":1}, {"x":2,"y":2} ] },
  { "kind": "owl",      "path": [ ... ] },
  { "kind": "platform", "path": [ ... ] }
]

길은 이웃한 칸을 차례로 이은 목록입니다. 첫 칸에서 출발해 끝까지 갔다가 되돌아옵니다. 눈덩이 길은 설 수 있는 땅, 발판 길은 구멍 칸, 부엉이 길은 맵 안 아무 칸이면 됩니다. 버전 3 이하 파일은 움직이는 것이 없는 것으로 읽습니다.

맵툴

길 그리기

  • 오른쪽 움직이는 것에서 [+ 눈덩이] [+ 부엉이] [+ 발판]을 누르면 길 그리기가 시작됩니다.
  • 칸을 차례로 누르면 길이 이어지고, 마지막 칸을 다시 누르면 지워집니다. Esc나 [완료]로 끝냅니다.
  • 그리드에는 길이 색 선으로, 출발 칸에는 표시가 그려집니다. 목록에서 고르거나 지울 수 있습니다.
  • 검증은 적과 발판의 움직임(턴)까지 따져 한 판에 모든 보석을 모을 수 있는지 봅니다.
